# NEO-VERIDIA // Cyberpunk Megalopolis 3D

Интерактивный 3D-симулятор киберпанк-мегаполиса в реальном времени на стеке **Vite + TypeScript + Three.js + GLSL** без использования внешних 3D-моделей, текстур и аудиофайлов.

## Возможности
- **Процедурный мегаполис (`InstancedMesh`):** кварталы, многоярусные небоскребы, генерация `CanvasTexture`-атласов окон и неоновых билбордов, аварийные маячки на крышах (~32 draw calls при 500 машинах в кадре).
- **Кастомные GLSL-шейдеры:**
  - Мокрый асфальт с процедурными лужами, кругами от капель дождя и френелевскими отражениями неона.
  - GPU-система дождя (16 000 частиц с учетом ветра) + экранный пост-эффект стекающих капель на линзе камеры.
  - Голографические вывески со сканлайнами, RGB-глитчем и эффектом CRT-схлопывания при отключении питания.
- **Симуляция воздушного трафика:** до 500 спинеров на 4 высотных эшелонах с контролем дистанции, перестроением между полосами, реакцией на боковой ветер и неоновыми шлейфами.
- **Интерактивный HUD и события:**
  - Плавная смена атмосферы: *Глубокая ночь*, *Токсичный рассвет*, *Кислотный дождь*.
  - Каскадный **Блэкаут** по 16 энергетическим секторам города с последующим перезапуском сети.
  - Режимы камеры: свободный полет (`Orbit + WASD`) и **Режим такси** (вид от 3-го лица или из кабины пилота).
- **Процедурный звук (Web Audio API):** синтез шума ливня, гула мегаполиса и эффекта Доплера при пролете транспорта мимо камеры.

## Запуск
```bash
npm install
npm run dev
```
